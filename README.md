# CMIT 国一介绍原文库

非官方的 CMIT 公开作品介绍检索库，提供年份、官网分类、关键词筛选及原文来源链接。

## 数据范围

- 820 篇去重后的历届官网自标国赛一等奖介绍。
- 2025 年公开介绍中有 77 篇匹配正式国一名单；当年官方名册共 659 件，其余 582 件本次未匹配到公开介绍。
- 抓取范围、核验状态与限制见“采集覆盖与核验.json”；未匹配不表示作品没有介绍。

## 使用

打开 `index.html` 即可使用，无需安装依赖。GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留原始静态文件。

## 来源与权利

内容来自 CMIT 官网公开作品展示，每条保留原始链接。原文版权归作品作者或相应权利人；请注明出处，不将他人文案、数据或成果作为参赛原创。本项目不是赛事官网，也不保证文案写法能提高获奖概率。

网站无登录、追踪脚本或外部模型调用。关键词筛选在浏览器内完成。
